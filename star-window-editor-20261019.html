    How to make the key (once per device)
    1. Open GitHub's new fine-grained token page (signed in as findastra).
    2. Name it astras-star-window and pick when it runs out. When it does, this page says so and you make a new one.
    3. Repository access: Only select repositories, then findastra/astras-star-window. Nothing else.
    4. Repository permissions: Contents: Read and write. Leave every other permission alone.
    5. Generate the token, copy it, paste it above and save.

    The key stays in this browser on this device and is only sent to GitHub. It can change the files of this one repo and nothing else. Forget it here, or delete it on GitHub, whenever you like.

    No key on this device? Your changes still work here: and give it to an assistant, or unzip it into the repo.
