astras-star-window

Astra's Star Window

A fat star that fades between my favorite pictures of my avatar. It is one hosted picture, so every page that shows it shows the same star, and when I change it here, it changes everywhere.

Put it on a page

GitHub README or Markdown

![Astra's Star Window](https://findastra.github.io/astras-star-window/star-window.svg)

HTML, floating to the right of a title

<img align="right" width="180" src="https://findastra.github.io/astras-star-window/star-window.svg" alt="Astra's Star Window">

GitHub keeps a copy of pictures for a few minutes, so after a change a README can show the old star for up to about 10 minutes.

Change the pictures

Open the star window editor

The editor is a tool of Portfolio Puffer. Upload a photo, drag it until it sits right in the star, and Capture. Saving needs Astra's own GitHub key for this repo.
